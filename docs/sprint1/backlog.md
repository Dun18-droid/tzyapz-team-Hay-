## 2. Обґрунтування пріоритетів

Розподіл пріоритетів виконано за бізнес-цінністю для користувачів та критичністю для замовлення нової функції керівництва «СтейНау»:
* **High (US-01 – US-05):** Критично важливі функціональні вимоги для клієнтської частини. Без сезонних коефіцієнтів, надбавок, знижок за тривалість, деталізованого чека та відображення політики скасування сервіс не вирішує головну бізнес-проблему замовника — «прозорі сезонні ціни та чесні правила скасування до бронювання».
* **Medium (US-06 – US-08):** Важливі сценарії управління та обслуговування. Включають безпосередній розрахунок повернення коштів при скасуванні та адміністративні інтерфейси менеджера для зміни параметрів тарифів без залучення розробників.
* **Low (US-09):** Допоміжна функція аудиту для адміністратора готелю в адмінпанелі. Вона підвищує зручність контролю розрахунків персоналом, проте її відсутність на першому етапі не блокує виконання основного клієнтського процесу онлайн-бронювання.
