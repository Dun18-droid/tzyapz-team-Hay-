# Моделі бізнес-процесів BPMN 2.0 (Спринт 1)

**Продукт:** «СтейНау» — бронювання готелів (`staynow`)  
**Виконавець (Інженер з тестування):** Андрущенко Костянтин  
**Рецензент (Тест-аналітик):** Дятлов Микола  

## Інструменти та формати
- **Редактор:** diagrams.net (draw.io)
- **Вихідні файли:** `.drawio` (нотація BPMN 2.0)
- **Експорт:** `.png` високої роздільної здатності для швидкого перегляду

## Перелік змодельованих процесів
1. `01_booking` — **Бронювання номера**:
   - Учасники: Пул «Гість», пул «СтейНау» (доріжки «Система», «Адміністратор»).
   - Логіка: Валідація полів, перевірка доступності, розрахунок вартості за сезонним тарифом (підпроцес), паралельне блокування номера та створення рахунку (шлюзи AND), обмін повідомленнями через межі пулів.
2. `02_cancellation` — **Скасування і повернення коштів**:
   - Учасники: Пул «Гість», пул «СтейНау» (доріжки «Система», «Менеджер»), зовнішній пул «Платіжний провайдер».
   - Логіка: Розрахунок штрафу залежно від днів до заїзду (XOR за даними), погодження умов гостем, вивільнення номера, повернення коштів через платіжний шлюз.

## Як відкрити та переглянути
1. Перейдіть на [app.diagrams.net](https://app.diagrams.net/).
2. Оберіть **File** -> **Open From** -> **Device...** і виберіть відповідний `.drawio` файл.
