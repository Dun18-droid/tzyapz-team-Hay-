### Description
F-120 (SRS 1.1) вимагає звіт заповнюваності номерів: за минулий період — за фактичними заселеннями, за майбутній — за підтвердженими бронюваннями з позначкою «Прогноз». Розділ «Report» цього не надає, тож адміністратор не може отримати заповнюваність за вибраний період.
Severity Normal: адмінпанеллю можна користуватися, але потрібного звіту немає. Priority P3: функція довідкова, інші кейси не блокує; сама вимога F-120 ще потребує підтвердження замовником (SRS 1.1, дефект № 7).

### Steps to reproduce
1. Відкрити у Chrome (нова сесія, інкогніто) сторінку входу адмінпанелі /admin локального стенду.
2. У поле Username ввести admin, у поле Password ввести password, натиснути «Login».
3. У меню адмінпанелі натиснути «Report».
4. Переглянути сторінку: шукати вибір періоду, значення заповнюваності і позначку «Прогноз».

### Actual result
Розділ «Report» не містить вибору періоду, показника заповнюваності за період і позначки «Прогноз».

### Expected result
Після кроку 4 можна вибрати період; для минулого періоду показано заповнюваність (частку зайнятих ночей) за фактичними заселеннями; для майбутнього — за підтвердженими бронюваннями, з позначкою «Прогноз» (F-120).

### Environment
localhost, restful-booker-platform; адреса, коміт, версія Chrome і ОС — аркуш «Environment» у docs/sprint3/execution-log.xlsx (Run 1, 25.10.2026). Chrome, нова сесія (інкогніто); обліковий запис admin / password (адміністратор).
