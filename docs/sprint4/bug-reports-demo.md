## BUG-013: Після Logout в панелі адміністратора відбувається редирект на головную сторінку замість форми входу

**Severity:** Minor  
**Priority:** P3  
**Environment:** demo v1 (Restful Booker Platform), Chrome (headless/normal), Windows 11  
**Linked TC / requirement:** TC-036 / F-85 (SRS 1.1)  
**Reporter:** Костянтин Андрущенко, 11.11.2026  
**Reviewer:** Мукоїд Едуард  
**Status:** open  

### Preconditions
Адміністратор авторизований у системі за адресою `BASE_URL + "admin"`, відкрито сторінку `/admin/rooms`.

### Steps to reproduce
1. Натиснути кнопку `Logout` у верхній панелі/шапці.
2. Перевірити URL та наявність елементів форми входу.

### Actual result
Система перенаправляє користувача на головну сторінку готелю (`/` або `BASE_URL`). Форма входу в панель адміністратора (`#username`, `#password`) відсутня.

### Expected result
За вимогою F-85 SRS 1.1 («Logout з адмінпанелі»), після виходу з облікового запису адміністратора система має повертати користувача на сторінку входу `/admin` з видимою формою авторизації (`#username`).
