## Процедура на модулі v2 (методичка 3.2)

1. Зберегти Surefire-звіти прогону на v1 (якщо не збережені у спринті 4 — перезапустити зараз і зберегти):
   ```
   mvn clean test
   cp -r target/surefire-reports docs/sprint5/surefire-v1/
   ```
2. Скопіювати `src/test/java/...` у `code/modules/staynow/v2` (або підключити v2 як модуль) і прогнати:
   ```
   cd code/modules/staynow/v2
   mvn -q -B test
   cp -r target/surefire-reports ../../../../docs/sprint5/surefire-v2/
   ```
3. Порівняти звіти **по кожному тесту**, а не лише за підсумковою кількістю падінь.
4. Для кожного тесту зі зміненим результатом — оновити `docs/sprint5/regression-log.xlsx` і статус дефекту в трекері.
